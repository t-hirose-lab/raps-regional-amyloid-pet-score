# Data

Raw data from ADNI and OASIS-3 are not included in this repository due to data use agreements.

## How to obtain the data

- **ADNI**: Apply at [adni.loni.usc.edu](https://adni.loni.usc.edu)
- **OASIS-3**: Apply at [nitrc.org/ir/](https://www.nitrc.org/ir/)

## Files included

- `raps_roi_weights.csv`: 8-ROI ElasticNet coefficients and bootstrap stability
- `bootstrap_roi_stability.csv`: Bootstrap selection frequency for all 80 ROIs (1,000 iterations)
